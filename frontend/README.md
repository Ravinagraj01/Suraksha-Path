# Disaster Dashboard Frontend

## Setup
1. `npm install`
2. `npm run dev`

## Environment
- `VITE_API_URL=http://localhost:8000`
- `VITE_WS_URL=ws://localhost:8000`

## Delivered UI
- Uizard-style light BI dashboard layout
- Collapsible sidebar + top header + global search
- KPI cards, charts, sortable/searchable table
- Leaflet OpenStreetMap integration
- WebSocket listeners for live SOS/shelter updates
- Role-based routing and protected layouts
- Geofencing location sender every 20 seconds
